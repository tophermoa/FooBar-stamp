# FooBar
Program sederhana menggunakan JavaScript untuk menampilkan angka dari 1 sampai 100 dengan aturan khusus:
* Jika angka habis dibagi 3 → tampilkan "Foo"
* Jika angka habis dibagi 5 → tampilkan "Bar"
* Jika angka habis dibagi 3 dan 5 → tampilkan "FooBar"
* Jika angka adalah bilangan prima → tidak ditampilkan
* Hasil akhir ditampilkan dalam urutan terbalik (100 → 1)

## 📌 Fitur
* Generate angka otomatis dari 1–100
* Validasi bilangan prima
* Replace angka sesuai aturan pembagian
* Reverse output sebelum ditampilkan
* Output ditampilkan di browser

`index.html`
File utama untuk menampilkan hasil di browser.

`script.js`
Berisi:
* Generate array angka 1–100
* Fungsi cek bilangan prima
* Logika FooBar
* Render hasil ke DOM
